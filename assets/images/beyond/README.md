Drop photos for the "Beyond the Lab" gallery in this folder.

Then reference them in `_data/gallery.yml`, e.g.

    - caption: "On court — badminton league night"
      emoji: "🏸"
      color: "teal"
      image: "badminton.jpg"

Tips:
- Landscape (4:3-ish) crops look best.
- Resize to about 1200px wide before committing so pages stay fast.
